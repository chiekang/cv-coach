# CV Coach

A one-page CV builder for the course **Financial Market and Global Business** (Fu Jen Catholic University).
Students fill in a short form in Chinese or English and get a one-page, ATS-friendly CV, with a live estimate of the five grading criteria: Easy to read, Right content, Proof, Strong words, Results.

- Start from scratch, or upload an old CV (PDF, Word, photo or pasted text) to improve it.
- Works with the student's own AI (Gemini, ChatGPT, Claude): copy the prompt, paste the answer back.
- Everything stays in the student's browser. Nothing is uploaded to a server.

Single file: `index.html`.
